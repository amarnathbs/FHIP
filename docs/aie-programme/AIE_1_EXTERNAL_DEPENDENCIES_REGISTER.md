# AIE-1 — External Dependencies Register

Tracks items AIE-1's own engineering cannot close by itself — each depends on
something owned outside this workstream (another programme, an operator
action, or a credential/subscription decision only the Product Owner can
make). Distinguished from AIE's own remaining implementation work
(tracked in `AIE_1_FINAL_CLOSURE_CERTIFICATION.md` §9/§14) precisely so a
future reader does not confuse "AIE hasn't built this yet" with "AIE cannot
build this without someone else acting first."

## What this register is not

This is not a list of things AIE-1 "gave up on." Every dependency above has
a real, implementation-complete, unit-tested AIE-side counterpart already
built and, where a real DEV database column doesn't block it, already
live-DEV verified. The register exists so a future reader — or a future
session picking up this work — does not mistake "waiting on someone else"
for "not done" or attempt to route around a genuine credential/cost/subscription
decision that is not this workstream's to make unilaterally.
