## Rollback at any step

Immediate: `AI_LIVE_PROVIDER_ENABLED=false` (stops every provider call; zero-cost features unaffected), `AI_SCHEDULER_ENABLED=false` (stops unattended submits; in-flight batches still reconcile), `AI_GLOBAL_ENABLED=false` (stops all AI features incl. Explain/NBA). Registry: disable the model row. Schedule: `cron.unschedule('module11-insight-pack-monthly')`. All are audited and reversible; no migration needs reverting.
