# Expected values: PDF routes accuracy corpus (hand-computed)

Generated by `scripts/pdf_routes_corpus.ts` from values written BY HAND in that file. Nothing here was read back from a parser or a model.
`tests/unit/pdfRoutesCorpus.test.ts` recomputes every identity below in integer cents and checks each figure is printed on its page.
SHA-256 of every file: `corpus/MANIFEST.sha256`. Dates are shown day-first.

Outcome vocabulary: **certified** = read by the certified reader, reconciles exactly, no warning. **review_required** = written, but needs the person (every AI-read statement is review required by design). **refused** = nothing written.
