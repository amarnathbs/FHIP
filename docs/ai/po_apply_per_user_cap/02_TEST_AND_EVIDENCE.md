## Against a clean `origin/main`

`tsc --noEmit`, `eslint` on every changed file and `npm run check:migrations` / `check:migrations:against-main` were run on the merged tip; results are in the final report. The repository-wide `vitest run` on a heavily loaded Windows machine produced 40-odd failing files in each of two runs; every one of them was re-run alone and compared with a clean `origin/main` worktree: all are either identical on `origin/main` (environment: no `.env.local` or `content/` in a worktree, Windows temp-directory races, 5 s timeouts of repo-walking tests) or pass alone. The only genuine difference found was caused by this change and was fixed (the two corpus RPC doubles, the `.env.example` declaration and the 0280 guard above). One failure is identical on `origin/main`: `m12cServerOnlySecretBoundary` "ENVIRONMENT_VARIABLES.md quoted Amplify forward list" (pre-existing doc drift, not touched).
